Cumulative distance chart for GoldenCheetah Trends.

Plots cumulative distance by calendar year and lets users switch to the active Trends date range or compared ranges.
Respects GoldenCheetah sidebar sport, code, and search filters, and uses the active date range in the Selection view. Remembers the last selected view when the chart refreshes.

Version 1.1 is a performance update to the original chart, improving loading for large activity histories while preserving daily totals and hover details. Runs locally without network dependencies.
